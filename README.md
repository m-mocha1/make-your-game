# Make Your Game (Brick Breaker)

A classic **Brick Breaker** game built with **JavaScript, HTML, and CSS**.

## Play / Run
- Open `index.html` in your browser.

## How to run locally
```bash
git clone https://github.com/m-mocha1/make-your-game.git
cd make-your-game
```
Then open `index.html`.

## Controls
- Move paddle: Left / Right Arrow keys (or A / D if supported)
- Start / restart: As implemented in the game UI

## Tech stack
- JavaScript
- HTML
- CSS
